FRAME Cinema MKV Batch v2.4.6-beta - DefaultDuration frame-timing normalization
================================================================================
- Added a gated MP4/non-Matroska -> MKV `default_duration` normalization. It is accepted only when the source field is absent, output field is a positive integer, and there is exactly one video track on each side.
- FFprobe verification requires equal source/output avg_frame_rate and r_frame_rate, with avg == r (CFR); output DefaultDuration must equal the frame-rate-derived nanosecond duration within 1 ns.
- Every packet must expose PTS and duration; packet counts, per-packet durations and relative PTS are compared within one coarser time-base tick, capped at 1 ms. Missing timing data, VFR/ambiguous rates, altered packet timing or insufficient timestamp precision are rejected.
- Added 10 dedicated regression tests: expected 24000/1001 CFR normalization accepted; wrong DefaultDuration rejected; VFR/ambiguous rates rejected; nonuniform source packet durations rejected; output duration changes rejected; packet-count changes rejected; relative PTS changes rejected; missing timing rejected; gate scope checked; strict MKV metadata comparison remains default.
- Full unittest suite: 81/81 PASS.
- Python syntax compilation: PASS.
- Synthetic FFmpeg stream-copy smoke test: generated 3-second 24000/1001 CFR MP4 (72 video packets), remuxed to MKV, then ran real FFprobe packet timing comparison; PASS.
- Real MKVToolNix end-to-end testing: NOT RUN. This build environment has FFmpeg/FFprobe but no mkvmerge/mkvextract. The user's macOS rerun remains the integration test.

FRAME Cinema MKV Batch v2.4.0-beta - Language Profiles and Audio Allowlist
==========================================================================

Current tests
-------------
- Python syntax compilation: PASS.
- 43 unit tests across language-profile, P0 publication/metadata, RARBG pairing and RARBG subtitle-classification suites: PASS.
- Normalization of common ISO 639-1 / ISO 639-2 pairs: PASS, including rus/ru-RU, zho/zh-Hans and fra/fr-FR.
- Audio allowlist: EN/JA/KO retained; explicit Russian and other known non-allowlisted languages excluded: PASS.
- Explicitly tagged Russian track with language=rus and language_ietf=ru-RU: safely classified as Russian and excluded: PASS.
- Und-tagged Russian track with clearly named "Russian Dub": safely inferred as Russian and excluded: PASS.
- Unknown / ambiguous audio language: fail-closed stop: PASS.
- FFprobe vs MKVToolNix explicit per-track language mismatch: stop before muxing: PASS.
- Retained audio defaults preserved; fallback selected only when all source defaults were filtered: PASS.
- English / Japanese / Korean subtitle profiles and .en / .ja / .ko sidecar suffixes: PASS.
- Mocked dual-subtitle mux command: --audio-tracks keeps only English/Japanese, excludes Russian, and applies fallback audio Default correctly: PASS.
- RARBG English-only modes remain guarded against Japanese/Korean profile selection: code-path guard retained.

Behavior notes
--------------
- Language profile is selected once per formal batch. A batch should contain works sharing the same primary subtitle language; mixed English/Japanese/Korean shows should be processed in separate batches.
- All formal mux workflows retain only identifiable English/Japanese/Korean audio tracks. Retained audio is copied, not re-encoded.
- If language tags are missing, only a clear track title can identify a track. Unclear tracks stop the episode rather than risking removal of English/Japanese/Korean audio.
- The selected profile determines subtitle Default and the extracted companion extension; it does not force the audio default unless all original audio defaults were filtered out.

Limitations
-----------
- Real MKVToolNix binaries are not installed in the build environment. Actual mkvmerge/mkvextract option behavior, MP4/MP4V track-ID mappings, and full macOS end-to-end output have not been certified here.
- Before batch use, test 1-2 representative files containing multiple audio languages (e.g. Russian + English), subtitles, chapters and attachments on the target Mac. Verify the resulting MKV contains only English/Japanese/Korean audio and plays correctly.
